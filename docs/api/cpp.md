# C++ API

Generated by Doxygen from the 83 public headers in
[`docs/api/public-headers.txt`](public-headers.txt) on every build. Tier 1 is the strategy, testing,
backtest and live API; tier 2 is the venue, codec, network and configuration extension API;
[Public API and header tiers](../reference/public-api.md) explains what each tier promises. Headers
that are not listed there are internal and are not in this reference: the engine loop, the rings,
the journal writer, the simulator internals and the venue connectors.

Browse the whole set: <a href="annotated.html">classes and structs</a>,
<a href="concepts.html">concepts</a>, <a href="namespaces.html">namespaces</a>,
<a href="files.html">headers</a>, <a href="functions.html">members</a>. The search box in the sidebar
searches the C++ reference only; the one at the top of the other pages searches the prose.

The prose counterparts are the [Strategy API](../reference/strategy-api.md),
[Fixed point](../reference/fixed-point.md) and [Journal format](../reference/journal-format.md)
reference pages, and [Architecture](../explanation/architecture.md) for how the pieces fit together.

The protocol implementations (FIX, Nasdaq ITCH and OUCH, CME MDP 3.0) are internal; the wire
formats are documented in [FIX 4.4](../reference/codecs/fix.md),
[Nasdaq ITCH and OUCH](../reference/codecs/nasdaq.md) and
[CME MDP 3.0](../reference/codecs/cme-mdp3.md). FIX and CME MDP 3.0 have no connector behind
them yet and are built only with `-DFASTMM_CODEC_FIX=ON` / `-DFASTMM_CODEC_MDP3=ON`
([Optional codecs](../getting-started/install.md#optional-codecs)).
