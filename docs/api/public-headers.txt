# FastMM public header manifest (ADR-0012, section 8). One header per line, relative to include/,
# after its tier:
#
#   tier1  strategy, testing, backtest and live API: stable within a minor version from 1.0
#   tier2  venue, codec, network and configuration extension API: documented, may change before 1.0
#
# Every header not listed is internal (engine internals, rings, containers, the journal writer,
# simulator internals, the reference venue connectors and protocol-specific codec headers) and may
# change in any release. docs/reference/public-api.md explains the tiers. Each listed header must
# compile on its own (ctest docs.public_headers, label docs); `net` marks headers that need a
# FASTMM_BUILD_NET build.
